# We部について

We部は、神戸電子専門学校の非公式学生コミュニティです。

## 概要

IT 学科の主に 1・2 年生を対象に、長期インターンへの挑戦を目標に、チーム制作を通じてエンジニアとしての基礎力を養うことを目的としています。チーム開発の経験と成果物を作ることで、どこに行っても腐らないエンジニアを育てることを目標としています。

- **対象：** 神戸電子専門学校 IT 系学科の学生（主に 1・2 年生）
- **参加費：** 無料
- **外部連携：** 株式会社オプティム（OB・社員が見学・意見をくれます）

## ゴール

We部が目指していること・実現したいことです。

- 長期インターン挑戦や Web 系就職に近づくための実践経験を積むこと
- 上級生下級生と一緒にチーム開発を行うこと
- 就活や技術の情報を共有し合えるコミュニティを育てること
- 技術力より熱量・意欲を大事にし、初心者でも挑戦できる場をつくること
- 成果物や発表を通じてアウトプット・発信する習慣をつくること
- 現役エンジニア（オプティム社員の皆様）との距離を縮め、業界感覚を養うこと
- メンバー自身がコミュニティを育てる主体になること

## ノンゴール

We部がやらないこと・目指していないことです。

- プログラミング文法を授業のように一から教える場にすること
- 受け身で参加するだけのコミュニティにすること
- MVP より先の完成度を最初から求めること
- 雑談だけを目的にした集まりにすること
- 就活テクニックだけを集める場にすること
- インターン選考への直接ルートを保証すること
- モバイル・ゲームなど Web 系以外の分野を主対象にすること

## 主な活動

- **チーム制作**（年2回・前期・後期） — メインの活動。4〜6人チームで成果物を作ります。
- **LT 会** — アウトプット共有の場（拡充予定）
- **就職対策** — インターン応募に向けたサポート（拡充予定）
