# We部について

We部は、神戸電子専門学校の非公式学生コミュニティです。

## 概要

IT学科の主に1・2年生を対象に、長期インターンへの挑戦を目標にしながら、チーム制作を通じてエンジニアとしての基礎力を養うことを目的としています。
ただ学ぶだけではなく、**仲間と一緒に考え、作り、形にする楽しさを知ることも** We部 の大事なテーマです。  
チーム開発の経験と成果物を作ることで、どこに行っても腐らないエンジニアを育てることを目指しています。

- **対象：** 神戸電子専門学校 IT 系学科の学生（主に 1・2 年生）
- **参加費：** 無料
- **外部連携：** 株式会社オプティム（OB・社員が見学・意見をくれます）
- **活動日：** 木曜日

## ゴール

We部が目指していること・実現したいことです。

- 長期インターン挑戦や Web 系就職に近づくためのチーム開発を積む
- 就活や技術の情報を共有し合える主体的なコミュニティを育てる
- 技術力より熱量・意欲を大事にし、初心者でも挑戦できる場をつくる
- 成果物や発表を通じてアウトプット・発信する習慣をつくる
- 「エンジニアって楽しい」と実感できる経験を増やす

## ノンゴール

We部がやらないこと・目指していないことです。

- プログラミング文法を授業のように一から教える場
- 受け身で参加するだけのコミュニティ
- インターン選考への直接ルートを保証する
- モバイル・ゲームなど Web 系以外の分野を主対象にする

## 主な活動

- **チーム制作**（年2回・前期・後期）  

メインの活動です。4〜6人のチームで企画から開発まで取り組み、成果物を作ります。  
実際に作って動かしてみる面白さを味わいながら、チーム開発の進め方も学びます。

- **LT会**  (不定期)

学んだことや作ったものを気軽に共有する場です。  
「俺はこんなものを作ったんだ！すごいやろ！」と自慢してみてください。笑

- **就職対策**

長期インターン応募や Web系就職に向けたサポートを行います。  
技術だけでなく、挑戦を形にして伝える力も身につけていきます。
