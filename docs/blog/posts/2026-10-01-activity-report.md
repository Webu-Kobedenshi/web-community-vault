# 10月1日の活動報告：3チームでデザインスプリント

秋休み明け最初の活動では、14名が3チームに分かれ、これから制作するアプリのアイデアを考えるデザインスプリントを行いました。今回は、We部のデザインスプリントの進め方に沿ってアイデア出しができるアプリ「アイディアブースト」を実際に使い、活動の中で使い勝手や動作を確かめました。

## 基本情報

| 項目 | 内容 |
| ---- | ---- |
| 日付 | 2026年10月1日（木） |
| 活動時間 | 15:30〜18:00 |
| 場所 | [オプティムワークスペース](../../access/optim-workspace.md) |
| デザインスプリントの時間 | 15:30頃〜17:30前後（チームごとに終了時刻に差あり） |
| 参加者 | 14名 |
| チーム構成 | 3チーム（6名・5名・3名） |
| メイン | チーム制作に向けたアイデア出し / アイディアブーストの実地検証 |

## 秋休み明けからチーム制作を本格的に開始

計画上はすでにチーム開発を進めている時期でしたが、これまではメンバーが十分に集まらないことや、新しく参加するメンバーへの対応もあり、今回が実質的に本格的なチーム制作のスタートとなりました。

9月17日の活動でチーム編成の発表は済ませており、今回はそのチームで作業を開始しました。新入生の参加も増え、3チームで進める体制になっています。この日のゴールは、各チームがデザインスプリントを通じて、制作に取り組むアイデアを考えることでした。

## アイディアブーストを使ったデザインスプリント

今回使った「アイディアブースト」は、We部で行っているデザインスプリントのワークフローに沿って、チームでアイデア出しを進められるホワイトボード形式のアプリです。活動での利用に向けて制作したもので、今回は参加メンバーに実際に使ってもらう実地検証も兼ねていました。

- 使用アプリのリポジトリ：[engineer-first/idea-boost](https://github.com/engineer-first/idea-boost)

15:30頃から各チームでデザインスプリントを始め、17:30前後にはおおむね終了しました。チームごとに終了時刻の差はありましたが、運営の所感としては、進め方に大きく迷う場面は少なく、アイデア出しを進められたと感じています。

一方で、実際に使ってもらうと、操作しづらい部分や、作業の邪魔になる UI、作り込みが十分でない部分が目立ちました。ワークを進めることはできたものの、アプリの使い勝手には改善が必要だと分かりました。

### 各チームで出たアイデアの方向性

各チームでは、次のようなテーマでアイデアが出ました。

- 生活習慣づくりの支援
- 会った人や交流の記録
- 就職活動での言葉遣いの支援

これらの方向性をもとに、次回に向けてモックアップを作り、制作内容を具体化していきます。

### 途中で発生したルームの切断

活動中には、Cloudflare の無料枠の上限に達し、ルームが切断されて再接続できなくなる問題が発生しました。この問題は当日中に解決しましたが、活動中に利用環境の問題へ対応することになりました。

## 運営の振り返り

### 利用環境の事前確認が足りなかった

今回の人数や利用時間で問題なく動くか、無料枠の範囲で活動を支えられるかを、事前に十分調べられていませんでした。アプリの機能だけでなく、実際の活動で使う環境まで確認する必要があったと感じています。

次回以降に向けては、想定人数での同時利用や、サービスの利用上限を事前に確認することが改善点です。接続できなくなった場合にも活動を続けられるよう、代替手段を用意しておくことも検討したいです。

### メンバーの様子を十分に把握できなかった

もう一つの反省は、運営の意識がアイディアブーストの使い方や操作のサポートに偏り、参加メンバーをよく見る余裕が足りなかったことです。

チーム制作の初動では、それぞれが話し合いの中でどう立ち回るか、どのようなことが得意そうか、どこにフォローが必要そうかを把握することも大切です。今回は、そうした役割やコミュニケーションの様子を十分に見られなかったことが心残りでした。

今後の改善案として、ツールの操作を支える担当と、チームの話し合いやメンバーの様子を見る担当を分けることが考えられます。一度の活動で得意・不得意を決めつけず、本人との会話も重ねながら、役割分担や必要な支援につなげていきたいです。

## 次回までの宿題

各チームには、今回出たアイデアをもとに、Figma や Figma Make などでモックアップを作る宿題を出しました。画面のイメージを形にし、次回の活動で具体的な仕様を考える材料にしてもらいます。

## 次回の予定

メンバーから「AI の使い方の講座をしてほしい」という要望があったため、次回は AI 活用についての講座を行う予定です。

制作については、次の流れを想定しています。

1. 宿題のモックアップをもとに、画面や使い方を具体化する
2. モックアップと PRD（プロダクト要求仕様書）を整える
3. 各チームでリポジトリを作成し、開発に進む

今回の活動で、3チームそれぞれの制作が本格的に動き始めました。次回はアイデアを画面と仕様に落とし込み、開発の準備を進めていきます。
