### Gemini CLI ハンズオン（16:45〜17:40）

運営の[コダックさんが作成した記事](https://zenn.dev/kodak_20/books/4e83363d81643d) をベースに、全員で VS Code → Node.js → Gemini CLI の順でインストールしていきました。運営陣が TA として張り付き、詰まったところを個別フォロー。

#### つまずきポイント：Windows で `npm` が通らない

Node.js を入れて `node -v` は通るのに **`npm -v` が PowerShell の実行ポリシーで弾かれる** 問題が複数人で発生しました。記事だけでは情報が足りなかったので、その場でネットで調べて [npm コマンドが使えない時の対処法（A.M.T.）](https://a-m-t.co.jp/blog/npm-command-disable/) の手順で、PowerShell の `ExecutionPolicy` を変更して解決しました。

運営側の学びとしては、**ハンズオン記事を作るときは、Windows 側で必要なものを一度全部アンインストールし切った「素の状態」で通しで検証する** のが重要だな、ということ。普段の自分のPCはすでに Node.js やパス設定が整っているので、初学者がぶつかる権限・実行ポリシーの壁が見えなくなりがちです。記事を更新するなら、新規 PC / クリーン環境で再現することを前提にしたいです。
