## 活動の流れ・内容

### 1) PRD のチーム内レビューと技術選定

6/4 の宿題として提出された PRD（要件定義）をチーム内でレビューしました。各チームは目的・ゴール・ノンゴール・ユーザーストーリーなどを確認し、その後、技術スタックの候補を議論して絞り込みました。

### 2) 部長による解説：タスク分解と開発ツール

部長より、タスク分解の正しい考え方を共有しました。

- 参考: https://zenn.dev/riozenn/articles/b5ddbe74f19038

また、チーム開発を安全・効率的に行うためのツール（mise、Lint と Format、CI）の使い方・方針説明があり、今後の開発ルールのベースが整いました。

- 参考: https://zenn.dev/riozenn/articles/de36cde8180331

### 3) 各チームでタスク分解と環境構築開始

説明を受けてから各チームで実際にタスクを分解し、issue作成。並行して環境構築を開始し、mise による Node.js 管理や Lint/Formatter 設定、CI の雛形作成などを行いました。メンバーは試行錯誤しつつ積極的に進めていました。

---

## メンバーの様子・気づき

- Web メンバーは「わからないことをすぐ聞く」姿勢が定着しており、説明中に Node.js の基本や PRD の書き方・考え方について積極的に質問して理解を深めていました。
- チームごとに作業スピードに差があり、環境構築で詰まる箇所は先輩や運営がフォローしました。
