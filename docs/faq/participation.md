# 参加資格・対象者

## IT系学科の学生なら学年やコースによらず参加できますか

エンジニアを目指す方なら、学年・コース問わず参加できます。ただし、チーム制作が活動の中心となるため、一般的な学生生活よりも学習・稼働時間が多くなることは覚悟しておいてください。

## 初心者でも参加できますか。参加前に最低限できていてほしいことはありますか

初心者でも参加できます。入部前の必須要件はありません。ただし、以下の知識があるとスムーズに活動できます。

- Git の基本操作
- `if` 文・`for` 文などの基礎的なプログラミングの知識
- Web アプリケーションの仕組みの概要

## 学外の人や他校の学生は参加できますか

現在は**神戸電子専門学校の学生のみ** を対象としています。他校や学外の方の参加は受け付けていません。
