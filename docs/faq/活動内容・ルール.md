# 活動内容・ルール

## 毎週参加が必須ですか。欠席・遅刻の扱いはどうなりますか

基本的には毎週参加してほしいですが、欠席は許容しています。欠席・遅刻の場合は、事前に **Discord で運営へ連絡** してください。

## オリエンテーション（GitHub・VSCode など）は参加必須ですか

必須ではありませんが、できるだけ参加をお願いしたいです。使用したプレゼンテーション資料は公開する予定なので、参加できない場合でも資料を見て各自で進めることができます。

## チーム分けはどうやって決まりますか

運営が以下を参考に決定します。

- GitHub 自己紹介ページのプロフィール
- 入部時の Google フォームの回答内容

チーム分け当日は運営が全員参加します。最初のチーム制作は、厳密なスキルマッチングより「まず動かすこと」を優先した組み合わせにします。

## チーム制作のゴールはどこですか

**MVP（最小限の動くプロダクト）のリリース** がゴールです。

完成度より「動くものを届けること」を優先してください。

## チーム制作が始まってから進め方がわかりません

コミットの粒度・タスクの分け方など、実装の進め方はつまずきやすいポイントです。このドキュメントサイトを充実させていくので、わからないことがあればその都度運営に聞いてください。
